# Tally Bar

A native macOS menu bar time tracker built with SwiftUI.

## Open and run

1. Open `Tally Bar.xcodeproj` in Xcode 16 or later.
2. Select the **Tally Bar** scheme and **My Mac** destination.
3. Run the app and click the timer icon in the macOS menu bar.

Requires macOS 14 or later. Bundle identifier: `com.dd.tallybar`.

This initial project contains the menu bar interface and a Quit action. Time tracking is not implemented yet.

Signing uses your local Mac identity for development; no Apple developer team is included.
